# 学习中心新增两个模块：设计说明

## 目标

将 `game_theory_site` 和 `tiny_habits_site` 作为两个完整、彼此隔离的静态模块加入现有 GitHub Pages 学习中心。主页从两个入口扩展为四个入口，新增模块分别使用 `/game-theory/` 和 `/tiny-habits/`，原有财富大脑、SFBT 与课程网址保持不变。

## 架构

两个来源网站均为不依赖后端的 HTML、CSS 和 JavaScript 应用，资源引用使用相对路径，学习数据保存在浏览器 `localStorage`。运行文件复制到 `public/game-theory/` 和 `public/tiny-habits/`；现有 GitHub Pages 构建脚本会把整个 `public/` 目录复制到发布产物，因此无需新增构建框架。来源目录中的部署说明、QA 脚本和书籍原始文本不属于浏览器运行资源，不进入公开站点。

主页沿用当前 TAO Learning Lab 的视觉语言与四卡片布局，为博弈论使用棋局/策略意象，为微习惯使用种子/成长意象。所有入口使用仓库子路径安全的相对链接。新增测试会检查两个入口、关键运行文件、无根路径资源引用和构建产物，随后用本地静态服务器验证页面与资源返回成功。

## 发布与恢复

改动通过功能分支写入同一仓库，验证后快进到 `main`，复用已经启用的 GitHub Pages 工作流。发布失败时保留现有线上版本，读取 Actions 日志后只修复对应步骤；不会删除或覆盖下载目录中的原始网站。
