# 学习中心扩展为六模块：设计说明

## 目标

在现有四模块 GitHub Pages 学习中心中加入行为改变课程和系统思考课程。新增入口分别为 `/behavior-modification/` 与 `/systems-thinking/`，原有四个模块的网址与数据保持不变。

## 架构与内容边界

两个来源均是浏览器直接运行的静态应用，使用相对 CSS、JavaScript 和图片路径，账户及学习进度保存在各模块独立的 `localStorage` 键中。运行资源复制到 `public/behavior-modification/` 与 `public/systems-thinking/`，由现有 Pages 构建脚本统一复制。`systems_site` 内部附带的 `bmlearn/` 是重复副本且未被入口引用；部署说明、规格、提取脚本、课程原文和缓存文件也不属于网页运行资源，均不公开。

主页继续采用 TAO Learning Lab 的纸张质感、深色描边与两列卡片网格。行为改变模块使用脑科学与练习意象，系统思考模块使用网络与整体观察意象；移动端继续单列。测试覆盖新入口、CSS、JavaScript、代表性课程图片与仓库子路径安全。发布使用功能分支和单一 Git 提交，GitHub Actions 成功后再验证首页、两个入口和资源 URL。

## 风险处理

两个模块的本地登录不是云端身份系统，用户应避免复用重要密码。若某张课程图片缺失，原应用会隐藏该图片但课程仍可使用；发布前会检查全部本地图片和线上代表性图片。下载目录保持只读，不删除或改写任何来源文件。
